# Optical Fault Prediction using MultiTask-LSTNet

## Overview

This project investigates deep learning approaches for predictive fault management in optical communication networks.

The main objective is to reproduce and extend the results presented in:

> "Learning Long- and Short-Term Temporal Patterns for ML-driven Fault Management in Optical Communication Networks"

The original LSTNet architecture is reproduced and evaluated using optical network datasets containing Hard Failure and Soft Failure scenarios.

Additionally, a Multi-Task Learning extension is proposed, combining:

- Time-series forecasting
- Fault detection

into a shared temporal representation model.

The goal is to improve the capability of detecting degradation patterns before optical network failures occur.
